# NGV Medialon Control Bridge 1.2.5

- Adds signed one-touch updates: the setup app downloads a verified DMG and
  opens the existing installer, which preserves applied site configuration.
- Adds the verified Panasonic PT-RZ120 projector pack with `PJON`, `PJOFF`,
  and `PJQUERY` aliases.
- Includes the current NovaStar MCTRL300, MCTRL4K and VX16s support.

This is an internally ad-hoc-signed build. It is not Developer ID signed or
notarized for broad public distribution.
